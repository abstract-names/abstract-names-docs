# Terminology

* Abstract: Chain abstraction platform providing global wallets
* Abstract Names: Naming protocol for readable identities
* Registry: ERC‑721 contract that mints and stores name data
* Resolver: Contract that maps names to addresses, text records, and contenthash
* Controller: Contract for pricing, phases, renewals, and reserved names
* Validator: Contract enforcing character rules and normalization
* Renderer: Onchain SVG and metadata generator
* Primary name: Reverse mapping from address → name
* Text record: Profile field stored on resolver (e.g., avatar, url)
* Content hash: Byte string for IPFS/Arweave references
* Tier: Pricing class by length (3, 4, 5, 6+)
